# Memory Allocator Simulator

Full-stack interactive simulator of Operating System memory allocation algorithms.

## Features
- First Fit, Best Fit, Worst Fit, Next Fit
- Live visual Memory Map
- Smart size slider
- Defragmentation (Compaction)
- Demo Scenario + Undo
- Real-time statistics & history
- Modern responsive UI

## Tech Stack
- Backend: Java + Spring Boot
- Frontend: React + Vite

## How to Run Locally

### Backend
```bash
cd backend
./mvnw spring-boot:run

### Frontend
```bash
cd frontend
npm install
npm run dev
